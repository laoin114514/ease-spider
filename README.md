#### 1.1.1 时间模式检测 (Time Pattern Detection)

**检测目标**：识别异常的时间提交模式

**检测指标**：
1. **快速连续AC检测**
   - 阈值：30分钟内连续AC ≥ 3道题，难度需要加权
   - 原理：正常学习需要思考时间，快速连续AC可能存在抄袭

2. **难度跳跃检测**
   - 难度跳跃超过三个等级
   - 检测缺乏基础题练习却能做高难度题
   - 原理：正常情况不存在突然跳跃难度做题
